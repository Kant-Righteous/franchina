# 法国紧急呼叫沟通指南

!!! info "快速查找直拨电话"
    如遇突发危急情况需要立刻拨号呼救，请前往 👉 **[紧急热线与求助入口速查](emergency.md)**。

在法国遇到人身侵害、突发急症或严重事故拨打求助电话时，应急调度中心（Centre de traitement des appels）会严格遵循标准化预案采集信息。留学生常因语言障碍或高度紧张而在通话中遗漏关键信息（如法国公寓至关重要的门禁代码 Digicode），从而延误宝贵的救援时间。

本指南系统梳理了在法国呼救时**“怎么沟通”**与**“必须提供什么”**，建议在平时熟读备用。

---

## 核心沟通原则

在接通 15、17、18 或 112 后，请牢记以下四大通话原则：

### 1. 保持冷静，优先回答接线员提问
法国应急接线员（Régulateur / Opérateur）受过专业的危机问询训练，其首要任务是在数十秒内评定险情等级并启动派车调度。
- **请抑制恐慌，不要只顾自己盲目宣泄**；
- 认真聆听接线员提出的每个问题，并**按对方的提问顺序如实、简短回答**。

### 2. 绝对不要主动挂断电话
法国公共救援系统实行**“边通话边出警”**机制：
- 在您与接线员对话的同时，后台系统通常已将信息同步推送给所在辖区的消防站、救护车队（SAMU/SMUR）或巡逻警车，**继续通话绝不会耽误车辆出发**；
- 接线员可能需要持续评估伤者状况并在急救人员抵达前提供指导；
- **必须严格等待接线员或急救医生明确告知 « Vous pouvez raccrocher »（您可以挂断了）后方可挂机**。

### 3. 通话开启免提，指派同伴下楼接应
- 接通后建议直接开启手机免提扬声器，以便在医生在线指导下实施紧急救护（如心脏按压、压迫止血、翻身侧卧）；
- 若现场有同伴或室友，**务必立即指派一人提前跑到大楼门外或主干道交叉路口挥手接应**，为消防员或急救医生指明大门与楼梯走向，节省宝贵时间。

### 4. 法语不熟练时的应对策略
留学生若担心法语无法顺畅交流，可采取以下两步：
- **开门见山提出语言诉求**：接通后第一时间明确告知：  
  « Bonjour, je parle peu français. Parlez-vous anglais s'il vous plaît ? »（您好，我法语不好，请问您讲英语吗？）  
  *(拨打 112 欧洲通用急救电话时通常配备多语种与英语接线协助)*；
- **若对方无法使用英语，直接采用「关键词报送法」**：慢速、清晰、重复报出核心法语词汇：  
  `Adresse`（报地址）+ `Digicode`（报门禁密码）+ `Problème`（险情性质，如 SAMU / Feu / Inconscient），应急系统会根据关键词与基站定位派员排查。

### ① 精确地址与通行代码（Où）

这是全法所有救援部门出动最关键的前提。法国住宅多为历史街区公寓，结构复杂：

1. **城市与邮政编码**：如 Toulouse 31000、Paris 75013；
2. **街道名与门牌号**：如 15 Rue de Metz；
3. **法国公寓内部通行细节（缺一不可）**：
   - **建筑物/楼栋号（Bâtiment）**：如 Bâtiment B；
   - **楼层（Étage）**：如 3ème étage；
   - **房号（Numéro d'appartement / Porte）**：如 Porte 12；
   - **门禁密码（Digicode / Code d'entrée）**：若大楼有两道门禁，须依次提供两组密码；
   - **对讲机姓名（Nom sur l'interphone）**：若门禁需按铃，说明门铃上贴的具体姓名。
4. **室外或道路**：若身处室外，请报出最近的十字路口、地铁站出口、知名商铺地标或路灯杆编号。

!!! warning "切勿遗漏门禁代码（Digicode）"
    每年均有留学生因在急救电话中忘记报出大门 Digicode 密码，导致急救人员抵达楼下后受阻于防盗铁门无法入内，酿成不可挽回的抢救延误。拨打前请务必确认门禁代码！

### ② 身份与回拨电话（Qui）

- **您的姓名与身份**：说明您是伤病员本人、室友、朋友还是目击路人；
- **能够随时接通的回拨电话号码（Numéro de rappel）**：以防由于网络弱导致通话意外中断，或救援车辆到达楼下找不到门牌时直接与您联络。

### ③ 险情性质与现场危险（Quoi）

- **发生了什么事情**：严重突发疾病、剧烈胸痛、昏迷、严重车祸、起火冒烟、入室盗窃、持械暴力等；
- **现场是否存在次生危险**：是否有燃气刺鼻异味、电线掉落、火势浓烟是否封锁通道、行凶嫌疑人是否仍滞留在现场或持有武器。

### ④ 伤员人数与生命体征（État des victimes）

- **涉及人数**：受害或伤病的人数及大致年龄；
- **意识状态（Conscience）**：患者是否有应答（拍肩呼唤是否有反应：Est-il conscient ? / Il ne répond pas）；
- **呼吸状态（Respiration）**：胸部是否有起伏、是否有规律呼吸（无呼吸者接线医生会立刻下令并指导心肺复苏 CPR）；
- **外伤与特征**：有无大喷射性出血、骨折变形、剧烈抽搐、面色苍白发青；
- 现场目前是否已采取某些急救手段（如正在压迫止血或胸外按压）。

## 114 紧急短信无声求助标准格式

如果身处尾随、暴力挟持、入室案发躲藏等**无法发出声响的危险险境**，或者属于听力、语言障碍人群，请直接向 **114** 发送短信求助。

法国国家 114 应急中心要求短信必须包含**四大关键要素**，单条完整发送：

!!! info "114 官方短信报送模板（可直接复制并按实际情况替换）"
    **URGENCE POLICE** *(或 SAMU / POMPIERS)*  
    **Adresse** : [街道门牌, 邮编城市, 楼栋 Bâtiment, 楼层 Étage, 房号 Porte, 门禁 Digicode]  
    **Situation** : [简明陈述险情，例如：Quelqu'un essaie d'ouvrir ma porte d'entrée / Je suis caché dans ma chambre]  
    **Victime** : [受困人数与伤情，例如：1 personne seule, pas de blessé pour le moment]  
    **Contact** : [您的回拨手机号]

## 12308 外交部全球领保热线行前材料准备

遇重大涉外安全事件、人身受限或失联，拨打外交部全球领事保护与应急热线 **+86 10 12308**（海外拨打需加拨国家区号 `+86`，接通后按 `0` 再按 `9` 直达人工客服）。

拨打前请尽可能在手边备齐以下信息：

- **当事人核心身份信息**：中文姓名、标准汉语拼音、性别、出生日期、中国护照号码及身份证号；
- **在法就读与居留信息**：所属院校、学生证号、所在城市及准确居住地址；
- **国内直系亲属紧急联系人**：父母或家属姓名、国内手机号码、电子邮箱与微信号；
- **事态关键要素与诉求**：事发经过、目前处境（如被拘押、失联天数、遭遇重大交通事故）、诉求事项，以及是否已向法国当地警方报案（若有，提供警察局所在区及立案号 Procès-Verbal）。

## 误拨紧急电话如何应对？

!!! danger "误拨切勿直接挂机"
    拨打 112、15、17 或 18 之后**绝对不能因为紧张直接按红键挂断**！  
    在法国，若紧急电话接通后立即挂断，调度系统会判定存在“求救人被暴力胁迫或陷入昏迷”的高危可能，警方或消防队将依据基站定位派巡逻警车上门排查。  
    **正确做法**：保持在线，对接线员诚恳说明：  
    « Bonjour, excusez-moi, c'est une erreur de numéro, tout va bien. »（您好，抱歉，这是误触拨号，一切平安。）  
    接线员核实确认无异常并回复许可后方可挂机。若事后收到来自 `0 800 112 112` 的官方回拨，请务必接听并配合确认。
