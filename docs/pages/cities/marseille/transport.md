# 本地交通

马赛的地铁、电车、公交及部分海上交通由 RTM 运营。城市南北跨度大、地形复杂，去 Luminy、Étoile 或海岸区域时，直线距离不能代表实际通勤时间。

## 网络构成

### 地铁与电车

| 线路 | 主要连接 |
| --- | --- |
| Métro M1 | La Rose、Saint-Just、Cinq Avenues、Saint-Charles、Vieux-Port、La Timone、La Fourragère |
| Métro M2 | Gèze、Joliette、Saint-Charles、Noailles、Castellane、Rond-Point du Prado、Sainte-Marguerite Dromel |
| Tram T1–T3 | 覆盖 Noailles、Cinq Avenues、La Blancarde、Canebière、Joliette、Arenc、Castellane 等走廊；终点与站名可能随扩建调整 |

完整线路、实时中断与无障碍信息以 [RTM 行程与线路页面](https://www.rtm.fr/se-deplacer) 为准；当前网络图可从 [RTM 官方 PDF](https://www.rtm.fr/sites/default/files/docs/Plan_r%C3%A9seau_1er_septembre_2025.pdf) 获取。

### 公交与大学片区

- **Luminy**：从 Castellane、Rond-Point du Prado 等方向换乘 B1、21Jet 等线路较常见，但应以当天规划结果为准。
- **Étoile / Saint-Jérôme / Château-Gombert**：通常从 M1 北段换乘公交。
- **海岸与南部社区**：公交班次可能受道路拥堵、活动和季节客流影响，应为换乘预留时间。

学校名称可能对应多个站点。建议直接输入教学楼地址，并分别测试工作日上课时段和晚间返程。

### 2026 年地铁工程

RTM 正在进行地铁自动化更新。根据 [RTM 地铁工程公告](https://www.rtm.fr/en/node/2333) 中标明“优先适用”的补充日历，截至 **2026-08-31（含）**：

- 周一至周三地铁从终点站的末班发车时间为 21:00，之后由 BM1A、BM1B、BM2 替代公交接续；
- 周四至周日地铁从终点站的末班发车时间为 00:30；
- 2026-08-16 05:00—14:00 地铁全线停运；同一公告另列 2026-09-13 05:00—14:00 的全线停运安排。

!!! warning "静态时刻不适用于施工期"
    上述时刻只适用于公告覆盖期，不能写成永久规则。晚间或特殊日期出行，应在当天查看工程页和 RTM 实时通知；2026-08-31 后也需重新核对下一阶段安排。

### 夜间公交

按照 [RTM 夜间公交页面](https://www.rtm.fr/plan-reseau-bus-soiree) 当前信息：

- Noctambus N1 连接 Vieux-Port 与 Luminy；
- Noctambus N2 连接 Vieux-Port 与 Einstein P+R；
- 通常在周四、周五和周六深夜运行，页面列出的 Vieux-Port 发车时刻为 01:30、02:30、03:30、04:30。

节假日、暑期或施工期间可能调整，凌晨出行应在当晚再次确认。

## 购买与验票

- 临时票可在自动售票机、服务点或按 RTM 规则在车上购买；车上票通常更贵。
- 实名学生订阅需要有效身份证明、照片和学籍材料，处理时间应留出余量。
- 每次进入地铁或登乘公交、电车时按要求验票；在有效换乘期内也应再次刷票。
- 票种、支持介质与线上办理入口统一从 [RTM 票价页面](https://www.rtm.fr/tarifs) 进入，避免通过过期截图购买。

## 公共自行车 levélo

levélo 是 Aix-Marseille-Provence Métropole 的电助力公共自行车服务。根据 [levélo 当前订阅说明](https://levelo.ampmetropole.fr/fr/sharing)：

- 普通长期订阅为 €6/月；26 岁以下长期订阅为 €3/月，两者均按 12 个月承诺和自动续订规则办理；
- 每日包含最多 4 次、每次前 30 分钟免费的行程，超时按分钟计费；
- 第 5 次及以后行程和超时会产生额外费用；
- 持符合条件的交通订阅者可选择组合方案，资格与计费以页面为准。

临时用户和最新计费也可查看 [levélo 价格说明](https://levelo.ampmetropole.fr/fr/blog/la-tarification)。还车时应确认车锁闭合并在应用中结束计费，海风较强时谨慎骑行。

## 海上交通

RTM 的 lanavette 在 Vieux-Port、Pointe Rouge、Les Goudes、L’Estaque 等方向提供季节性海上接驳。2026 年当前公告的主要运营期为 **2026-04-25 至 2026-09-27**，但线路分段、天气停航和票价各有规则，详见 [RTM lanavette 页面](https://www.rtm.fr/lanavette)。

!!! warning "海上接驳不是全年稳定通勤线"
    强风、浪况、技术问题或季节结束均可能导致停航。重要行程应准备陆路备选方案。

## 铁路与机场

### Marseille Saint-Charles

Saint-Charles 同时连接 TGV、Intercités、TER、地铁 M1/M2 和多条公交。马赛市内部分 TER 车站可用于跨区通勤，但票种覆盖并不完全相同，站点概览可查 [RTM 的马赛 TER 车站页面](https://www.rtm.fr/gares-ter-marseille)，具体列车与票价以 [SNCF Connect](https://www.sncf-connect.com/) 为准。

### Marseille Provence 机场

A1 接驳巴士连接 Marseille Saint-Charles 与 Marseille Provence 机场。机场官方页面公布正常情况下车程约 25 分钟、日间高频运行，但道路拥堵会影响时间，详见 [机场 A1 接驳说明](https://www.marseille.aeroport.fr/parkings-et-acces/acces/bus/marseille-gare-st-charles)。

机场接驳价格在 2026 年有调整，本指南不固化一个可能很快过时的金额；购票前从 [机场官方接驳商店](https://store.marseille.aeroport.fr/fr_FR/reservation/navettes-bus/) 查询成人、青年或往返产品的实时价格。

## 通勤选择建议

1. 确认课程实际在 Centre、Timone、Luminy、Étoile，还是 Aix-en-Provence。
2. 用具体门牌地址在工作日高峰测试路线，不能只看线路图上的最近站。
3. 对依赖单一公交的校区，另查周末、夜间和罢工时的备选路线。
4. 2026-08-31 前晚间乘地铁，必须查看自动化工程公告。
5. 前往机场、岛屿或 Calanques 时，为道路拥堵、强风和临时管制预留余量。
