# 巴黎本地交通

巴黎及大巴黎地区（Île-de-France）拥有欧洲最密集、最复杂的城市公共交通系统，主要由 RATP 和 SNCF 进行联合运营。

## 🚇 交通工具介绍

*   **地铁（Métro）**：共14+2（bis）条线，网络密集覆盖小巴黎及部分近郊。班次极密，是市区内最主流的出行方式。
*   **区域快铁（RER）**：共 A, B, C, D, E 五条主线。连接小巴黎和广阔的外围郊区。速度比地铁快很多，但在小巴黎内停靠站少。**注意**：RER 晚点、故障和罢工是家常便饭，需要习惯。
*   **远郊火车（Transilien）**：线路以字母编号（如 H, J, L, N 等），主要从巴黎的各大火车站辐射向更远的法兰西岛卫星城。
*   **有轨电车（Tramway / T线）**：分布在巴黎环城边缘及近郊，非常准时且舒适。
*   **公交车（Bus）**：路网极为发达，适合不赶时间或者搬运重物时乘坐，同时也能当观光车欣赏街景。此外还设有**夜班车（Noctilien）**，全称为 "N" 开头的线路，满足深夜和凌晨的出行需求。

## 💳 交通卡与票价

在巴黎常住，拥有一张交通卡（Cartes Navigo）是每天出行的必需品。大巴黎交通按圈（Zones）划分，共1-5圈。

### Imagine R Étudiant（学生年卡）
对于 **26岁以下** 的在校学生（高中生、大学生），这绝对是最划算的选择：
*   **权益**：全年无限制乘坐大巴黎 **1-5圈内** 的所有常规公共交通。周末、法国节假日也是完全免费在1-5圈穿梭（非常适合周末去远郊如凡尔赛宫、迪士尼玩）。
*   **价格**：2026–2027 学年 zones 1–5 为 **401.30€/年**（含 8€ 手续费，可一次性付清或分 9 期月付），明显低于成人 Navigo 年卡。年费每学年由法兰西岛交通局调整，办理前以官方页面为准。
*   **办理方法**：在 [Île-de-France Mobilités 官网](https://www.iledefrance-mobilites.fr/titres-et-tarifs/detail/forfait-imagine-r-etudiant)线上提交申请，需上传注册证明（Certificat de scolarité）等材料，受理周期较长，建议开学初尽早办理。

### Navigo Mois / Semaine (月卡/周卡)
对于超过26岁的学生或是实习生，可以办理常规的 Navigo：
*   可以直接办理“全圈通”（Toutes Zones, 1-5圈）的包月或包周卡。
*   现在非常方便的一点是，支持直接使用手机 NFC 或绑定在 Apple Wallet / Google Wallet 中充值和刷卡过闸。

### Ticket t+ 及次票
如果你住在离学校非常近的地方，极少坐车，可以选择按次收费。
*   Ticket t+ 可以用来乘坐小巴黎内的地铁、公交和指定范围的 RER 等。
*   **注意**：传统的磁条纸质车票正在被逐渐淘汰。官方建议购买一张无记名无照片的 **Navigo Easy** 储值卡来充值存放你的次票（Carnet）；当然你也可以直接用手机上的官方 APP 进行充值并刷手机过闸机。

!!! tip "实用常用交通 APP 推荐"
    在巴黎出行，下载几个靠谱的 APP 可以帮你规避很多罢工、施工导致的麻烦：
    - **Île-de-France Mobilités**：官方APP，不仅可以查路线，还可以直接用手机购买充值各类车票（必备）。
    - **Bonjour RATP**：传统官方APP，随时查看交通线路的异动和通告。
    - **Citymapper**：经常比谷歌地图提供更本土化、更精准的换乘组合方案，不仅包含公交，还会综合共享单车路线。
