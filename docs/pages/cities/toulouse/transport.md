# 交通出行

## 公共交通
图卢兹的公共交通由 **[Tisséo](https://www.tisseo.fr/)** 公司运营，系统高效且覆盖广泛，主要包括地铁、有轨电车和公交网络。可以在 Tisséo 官网查询时刻表、路线图及票价信息。

### 地铁
图卢兹地铁采用**VAL自动轻轨系统**（Véhicule Automatique Léger），目前运营两条线路：
- **A线**：12.5公里，18个车站，日均客流量约21.9万人次；
- **B线**：15公里，20个车站，日均客流量约20.7万人次。
两条线路共设38站，总长度27.5公里。第三条线路（C线）预计于2028年开通。

![图卢兹VAL地铁列车](https://upload.wikimedia.org/wikipedia/commons/thumb/b/b8/VAL_52m_Toulouse.jpg/250px-VAL_52m_Toulouse.jpg){: align=right width=300 }

### 有轨电车
图卢兹有轨电车系统目前有T1、T2等线路，连接市区与周边区域，如布拉尼亚克机场（Blagnac Airport）。

### 公交
Tisséo运营149条公交线路（含Linéo快速公交），其中Linéo是具备高服务水平的快速公交（BRT），共10条线路（2023年），使用大容量车辆，发车频率高，服务于地铁未覆盖区域。

## 铁路
图卢兹是西南法重要铁路枢纽，主要车站为**图卢兹马塔比欧站**（Gare de Toulouse-Matabiau），连接以下干线：
- 波尔多–塞特线（可通达巴黎、里昂、马赛）；
- 图卢兹–巴约讷线（通往巴斯克地区及西班牙）；
- 图卢兹–欧什线（通往比利牛斯山区）；
- 奥尔良–蒙托邦线（经利摩日通往巴黎）。
目前尚无高铁直达，但可通过现有线路运行TGV列车。未来**波尔多–图卢兹高铁**（LGV Bordeaux-Toulouse）建成后将大幅缩短与巴黎的旅行时间。

## 航空
**图卢兹-布拉尼亚克机场**（Aéroport de Toulouse-Blagnac）是法国第六大机场，提供国内及国际航班，主要服务于空客总部及航天产业人员出行。机场通过有轨电车T2线与市区相连。

## 道路与高速公路
图卢兹由多条高速公路环绕，构成发达的路网：
- **A62**：通往波尔多（西北）和蒙托邦（东北）；
- **A61**：通往纳博讷和地中海沿岸，衔接A9高速；
- **A68**：通往阿尔比和里昂方向；
- **A64**：通往塔布、波城和巴斯克地区；
- **A66**：通往富瓦和安道尔。
城市外围有**图卢兹环城公路**（Périphérique），部分路段由“彩虹环线”（Rocade Arc-en-Ciel, D980）补充，缓解交通压力。早晚高峰时段环城路常拥堵，日均车流量超13.5万辆。

## 自行车出行
图卢兹积极推广绿色出行，设有完善的自行车道网络和公共自行车系统（VélôToulouse），鼓励市民骑行通勤。
