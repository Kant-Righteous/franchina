# 关于我们

欢迎来到 **FranChina** —— 陪伴您走过留法生活的百宝箱！💼✨

## 🌟 官方主办与初心

**FranChina** 是由**图卢兹中国学者学生联合会（UCECF-ST）**发起并负责日常运维的公益性留法生活综合信息平台。

每一个选择法兰西的留学生，都曾经历过面对繁琐行政手续时的迷茫与无助。从办理长居、申请 CAF，到激活 Ameli 医保，法国特有的行政流程往往令人头疼。图卢兹学联秉持“服务学人”的根本宗旨，联合本地与全法多位优秀学长学姐，将多年积累的第一手求学与生活经验转化为清晰、系统的避坑指南。

我们希望这里不仅仅是一个信息查阅工具，更是学长学姐经验代代相传、传递温暖与互助的留法港湾。

## 📍 立足图卢兹 · 辐射全法

* **立足大本营（图卢兹）**：作为深耕本地二十余年的学人社群，图卢兹学联为本地新老生提供最接地气的迎新答疑、本地公共交通、高校校区分布、租房避坑与学联社群支持。
* **辐射全法通用指南**：从行前护照公证、签证递签、落地两周清单，到长居验证、国家医保（Ameli）、银行税务与生活出行，为全法各地的中国留学生梳理全法通用的核心办事实操。
