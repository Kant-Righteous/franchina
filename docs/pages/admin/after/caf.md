# CAF 住房补助 (APL)

!!! quote "学长学姐说"
    来法国第一件大事就是申请房补！不要拖，**房补是从你“申请当月”开始算的**，不是从你“入住当月”算。哪怕材料还没齐（比如还没拿到正式居留卡），也要先去官网把号注册了，把申请表填了！

## 1. 它是怎么回事？
法国政府给低收入居民（包括外国留学生）的住房补贴，全称 **Aide Personnalisée au Logement (APL)**。
绝大多数中国留学生都能申请，金额通常在 **100€ - 200€ / 月** 不等（根据房租、城市、收入计算）。

## 2. 只有这几种情况**不能**申请
*   你持有的是短期的旅游签证（Visa C）。
*   你的房子不符合标准（比如面积小于9平米，不过正规学生公寓都符合）。
*   你和房东有亲属关系。

!!! info "长期学生签证 (Visa D) 均可申请"
    只要你的 Visa 上写着 "Etudiant"，且有效期大于 3 个月，你就有资格申请。

## 3. 核心时间线（重要！）
1.  **入住 (Check-in)**：拿到住房合同 (Bail) 和 住房证明 (Attestation de loyer)。
2.  **立刻申请**：拿到合同的当月，立刻去 [caf.fr](https://www.caf.fr) 官网申请。
3.  **首月缺口**：**入住的第一个月通常没有房补**（或者很少）。例如 9月1日入住，从10月开始计算，11月5日左右收到第一笔钱。
4.  **材料补交**：如果此时没有出生公证双认证或正式居留卡，**也要先申请**，后续在系统里补传。

## 4. 准备材料清单
在申请过程中，你通常需要上传 PDF 扫描件：

*   [x] **护照** (Passeport)
*   [x] **签证页 + 入境章** 或 **居留卡** (Titre de séjour)
*   [x] **出生公证双认证** (Act de naissance traducté par un traducteur assermenté)
    *   *这是最大的坑：国内办公证+外事认证带过来，最好再找法国宣誓翻译做一遍翻译。CAF 对此要求很严格。*
*   [x] **银行 RIB** (Relevé d'Identité Bancaire) - 必须是法国银行账户
*   [x] **住房合同** (Bail de location)
*   [x] **房东填写的证明** (Attestation de loyer) - 学生公寓通常会直接给你这张纸，私人房东需让他填。

## 5. 申请流程概览
目前全法申请流程统一在 [caf.fr](https://www.caf.fr) 进行（全法语）。

1.  **创建账户 (Créer un compte)**
    *   选择 "Demander une prestation" -> "Logement"。
    *   如果是第一次，选择 "Faire une demande without account" (或者类似 creating profile)。
2.  **填写信息**
    *   **Etat civil**: 姓名、生日等。
    *   **Logement**: 地址、房租金额（不含杂费 Charges）、入住日期。
    *   **Situation professionnelle**: 选 "Etudiant"，是否拿奖学金（一般指法国政府奖学金，没有就填否）。
    *   **Coordonnées bancaires**: 手动输入 RIB 上的 IBAN 号码。
3.  **上传材料**
    *   按提示上传 PDF。如果不全，可以稍后在 "Mon Compte" -> "Suivre mes démarches" 里补。
4.  **下载凭证**
    *   提交后会生成一个 Recap，保存好。你会得到一个 **Numéro Allocataire** (房补号)，以后登录全靠它，**千万别丢**。

## 6. 常见问题 (FAQ)

### Q: 房补是发给我还是发给公寓？
A: 可以选择。
*   **发给自己**: 钱打入你的银行卡，你全额交房租。
*   **发给房东 (Tiers payant)**: 钱直接给公寓，你只交（房租 - 房补）的差额。CROUS 和有些私立公寓强制这样做。

### Q: 我还没办公交卡/还没拿到出生公证，能申请吗？
A: **能！** 先填表占坑，确保申请日期（Date de demande）锁定在入住当月。材料可以后面补，但钱是从你申请那个月开始算的。

### Q: 合租 (Colocation) 怎么填？
A: 必须如实填写 "Colocation"。
*   CAF 会按“房租除以人数”或者“每人承担的份额”来重新计算房补。
*   通常比单人申请略低一点点，但如果隐瞒被查到会罚款。

### Q: 几个月了还没收到钱？
A: 正常... 法国行政效率懂的都懂。
*   先检查账户里是否有 "Demande de pièces complémentaires" (缺材料)。
*   如果材料齐了显示 "En cours de traitement"，只能等。
*   可以通过 APP 里的 "Contacter ma CAF" 写邮件催，比打电话好用。

---
*注：具体金额计算以 CAF 官方审核为准，以上经验适用于全法大多数情况。*
