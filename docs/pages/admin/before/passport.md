# 中国护照首次办理

准备赴法国留学时，通常需要先办理中国普通护照，再使用护照完成学校注册、法国学生签证申请和后续出国手续。

首次申请普通护照，应向中国境内的公安机关出入境管理部门提出申请，不需要联系法国使领馆，也不需要使用“中国领事”APP。

## 去哪里办理

中国内地居民可以在全国任一公安机关出入境管理窗口申请普通护照，不一定必须回户籍所在地。

你可以选择：

* 户籍所在地的公安机关出入境管理大厅；
* 当前学习、工作或居住城市的出入境管理大厅；
* 其他方便前往的公安机关出入境管理窗口。

办理前，建议通过国家移民管理局政务服务平台、当地公安机关出入境管理部门或 `12367` 服务热线查询：

* 办证大厅地址；
* 开放时间；
* 是否需要预约；
* 照片提交方式；
* 是否提供邮寄取证服务。

!!! note "普通护照可以全国通办"
内地居民可以在全国任一出入境管理窗口申请普通护照，异地申请不受户籍地、居住地等条件限制，基本申请材料与户籍地办理一致。

## 常见材料

年满16周岁的中国内地居民首次申请普通护照，通常需要提交：

* 符合《出入境证件相片照相指引》标准的照片；
* 《中国公民出入境证件申请表》；
* 本人有效居民身份证。

居民身份证正在领取、换领或补领期间，可以提交有效的临时居民身份证。

申请表通常可以根据受理窗口指引填写。照片的拍摄和提交方式可能因地区而异，部分办证大厅提供现场拍照服务，部分地区可能要求提前准备照片或照片回执，应以当地要求为准。

## 特殊情况

### 未满16周岁

未满16周岁的申请人应由监护人陪同办理。

除普通申请材料外，通常还需要提交：

* 出生证明、户口簿等监护关系证明；
* 监护人的居民身份证或护照等身份证明。

监护人无法陪同的，可以委托他人陪同，但还需要提交：

* 监护人出具的委托书；
* 陪同人的居民身份证或护照等身份证明。

## 办理流程

1. 查询附近的公安机关出入境管理窗口及开放时间。
2. 根据当地要求提前预约，或者到现场取号办理。
3. 携带居民身份证等申请材料前往办证窗口。
4. 填写并确认《中国公民出入境证件申请表》。
5. 按当地要求提交符合标准的出入境证件照片。
6. 按规定完成身份核验和指纹信息采集。
7. 仔细核对申请表中的姓名、姓名拼音、性别、出生日期和出生地点等信息。
8. 缴纳普通护照办理费用。
9. 领取并保存《受理申请回执单》。
10. 按照回执提示查询办理进度。
11. 选择到办证窗口领取护照，或按照当地提供的方式邮寄领取。
12. 收到护照后，立即核对护照上的全部个人信息。

!!! warning "申请护照时一定注意核对各种信息"

## 费用

普通护照的官方收费标准为：

> **120元一本**

如选择邮寄领取，可能还需要另行支付邮寄费用，具体以当地服务标准为准。

## 办理时间

一般情况下，普通护照的办理时限为：

| 办理情况      |           官方办理时限 |
| --------- | ---------------: |
| 在户籍地申请    | 自受理申请材料之日起7个工作日内 |
| 跨省异地申请    |              20日 |
| 符合条件并获批加急 |           5个工作日内 |

偏远地区、交通不便地区或者存在特殊情况，不能在规定时间内签发护照的，办理时间可能延长。

!!! note "以受理回执为准"
实际领取日期以《受理申请回执单》和当地出入境管理部门通知为准。学校申请或签证时间临近时，不要按照最短办理时限倒推申请日期，应尽早办理。

## 留学报到临近，可以申请加急吗

可以提出申请，但是否批准由公安机关出入境管理部门审核。

“出国留学报到时间临近”属于可以申请加急办理普通护照的情形之一。申请时，需要提交能够证明紧急情况的相应材料，例如：

* 法国学校录取通知书；
* 学校开学或报到日期证明；
* 其他能够说明需要紧急出境的材料。

加急申请获批后，公安机关出入境管理部门应当在5个工作日内审批签发并制作普通护照。

加急不是自动获得的服务，也不是普通申请人都可以选择的付费项目。是否符合加急条件，以及需要提交哪些材料，以受理机关审核结果为准。

## 护照有效期

普通护照的有效期按照申请人年龄确定：

* 16周岁以上：护照有效期为10年；
* 未满16周岁：护照有效期为5年。

护照有效期不等于可以在法国停留的时间。赴法国长期学习，还需要申请并取得相应的法国长期学生签证。

## 常见问题

### 一定要回户籍所在地办理吗？

不一定。

中国内地居民可以在全国任一公安机关出入境管理窗口申请普通护照，不受户籍地、居住地等条件限制。

不过，跨省异地申请的官方办理时限通常为20日，在户籍地申请通常为7个工作日内。如果时间紧张，可以综合考虑办理地点和办理时间。

### 必须拿到法国学校录取通知书才能办理护照吗？

一般不需要。

中国公民因学习、旅行、就业等非公务原因出国，可以凭身份证申请普通护照。法国学校录取通知书通常不是普通学生首次申请护照的常规材料。

但是，申请留学加急办理时，需要提交能够证明报到时间临近的相应材料。

### 首次申请护照可以完全网上办理吗？

一般不可以。

首次申请普通护照需要申请人本人前往公安机关出入境管理窗口，提交材料并按规定完成身份核验和指纹信息采集。

目前部分城市开展的出入境证件“全程网办”主要适用于符合条件的普通护照换发、补发，不适用于普通护照首次申领。

### 可以让父母代办吗？

一般不可以。

首次申请普通护照需要申请人本人到场。未满16周岁的申请人本人也需要到场，并由监护人陪同办理。

### 可以在学校所在地办理吗？

可以。

普通护照已经实行全国通办，在外地读书的学生可以就近选择公安机关出入境管理窗口申请，不需要专门返回户籍所在地。

### 办好护照就可以去法国了吗？

不可以。

护照是中国公民出入国境和在国外证明国籍、身份的证件。赴法国长期学习，还需要完成法国留学申请程序，并取得有效的法国学生签证。

### 护照下来后需要做什么？

收到护照后，建议：

1. 核对护照上的姓名、姓名拼音、性别、出生日期、出生地点和有效期；
2. 扫描护照资料页，并妥善保存电子备份；
3. 不要在护照上涂写、盖章或粘贴无关材料；
4. 使用护照信息填写法国学校、Campus France 和签证申请资料；
5. 购买机票时，确保乘机人姓名与护照上的姓名拼音一致。
