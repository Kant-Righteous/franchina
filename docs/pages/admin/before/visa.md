# 办理法国学生签证

中国内地学生赴法国长期学习，通常需要先完成法国高等教育署相关程序，再通过 **France-Visas** 填写签证申请，并按照系统指引前往签证受理中心递交材料和采集生物信息。

!!! warning "先确认签证类型"
    本文主要介绍成年学生常见的 **长期学生签证 VLS-TS，mention étudiant**。短期课程、未成年人赴法就读、交流项目、博士合同或学生竞赛等情况可能适用其他签证类型。请先使用 [France-Visas 签证助手](https://france-visas.gouv.fr/) 判断，不要只根据他人经验选择类别。

## 整体流程

| 阶段 | 主要平台 | 你需要完成什么 |
|---|---|---|
| 留学前置程序 | [法国高等教育署中国](https://chine.campusfrance.org/zh-hans) / Études en France | 按个人项目完成材料审核、面试或免面试程序 |
| 签证申请 | [France-Visas](https://france-visas.gouv.fr/) | 确认签证类型、填写申请表、生成材料清单 |
| 预约递签 | France-Visas 指定的 TLScontact 受理中心 | 预约时间、递交材料、采集指纹和照片 |
| 等待结果 | 受理中心查询页面 | 跟踪护照状态，按通知领取或接收护照 |
| 抵法后 | [ANEF](https://administration-etrangers-en-france.interieur.gouv.fr/) | 如持 VLS-TS，在规定期限内在线验证 |

!!! note "法定流程与经验建议"
    表格中的平台和步骤属于正式申请流程；提前准备扫描件、保留复印件、避免购买不可退改机票属于经验建议。两者不要混为同一类要求。

## 第一步：完成留学前置程序

中国内地属于 **Études en France（EEF）** 程序覆盖范围。多数赴法长期学习的申请人，需要先在法国高等教育署系统完成与其项目对应的程序；录取方式、项目类型和个人身份不同，具体步骤可能不同。

你应当确认：

- 录取项目是否要求走 Études en France。
- 是否需要参加高等教育署面试。
- 系统中的姓名、护照号码、录取项目和开学日期是否一致。
- 是否已收到可以进入签证阶段的系统通知。

办理要求以[法国高等教育署中国](https://chine.campusfrance.org/zh-hans)账户中的通知为准。不要使用他人的流程截图代替你自己的系统要求。

## 第二步：填写 France-Visas 申请

进入 [France-Visas](https://france-visas.gouv.fr/)，先使用签证助手确认类别，再创建申请。填写时重点检查：

- 姓名、出生日期、护照号码与护照完全一致。
- 预计入境日期与学校开学、住宿起始时间能够对应。
- 学校名称、校区、课程名称和学习周期与录取文件一致。
- 法国地址应填写真实住宿信息；尚未确定长期住房时，按现有住宿证明填写。
- 资金来源应与银行证明、奖学金或资助材料一致。

提交后下载申请表、登记回执和系统生成的材料清单。**材料清单由个人情况和签证类别决定，应以你自己的 France-Visas 清单为准。**

## 第三步：准备递签材料

下列内容是长期学生签证的常见材料框架，不替代 France-Visas 为你生成的清单。

### 身份与申请文件

- 有效护照及按清单要求提供的资料页、签证页复印件。
- France-Visas 申请表和登记回执。
- 符合签证照片规格的近期证件照。
- 户口、旧护照或其他身份材料，仅在个人清单要求时提供。

### 学业材料

- 法国学校正式录取或预注册证明。
- Études en France / 法国高等教育署程序完成证明。
- 与申请相关的学历、成绩、语言或项目说明材料。

### 住宿与资金材料

- 抵法初期的住宿证明，例如学校宿舍证明、租赁文件、酒店预订或接待证明。
- 能够说明学习期间生活来源的银行、奖学金、担保或资助材料。
- 资助人承担费用时，按清单提供资助声明、关系和资金来源证明。

!!! warning "金额和材料必须对应"
    资金标准、签证费、受理服务费和可接受材料可能调整。请以 [France-Visas](https://france-visas.gouv.fr/) 生成的清单及受理中心付款页面为准，并确保你提交的金额和证明方式满足当次明确要求；“以平台为准”不能替代资金证明本身。

## 第四步：预约并递交申请

中国内地的申请由 France-Visas 指引至对应的 TLScontact 受理中心。受理地点和预约入口取决于你的居住地及申请类别，应从 [France-Visas 中国申请页面](https://france-visas.gouv.fr/en/web/france-visas/china)进入，不要使用搜索广告中的预约链接。预约后按确认信要求前往，通常需要：

1. 携带预约确认、申请文件和全部材料。
2. 现场核对材料并采集指纹、照片等生物信息；是否可以免采以受理中心判断为准。
3. 支付页面或现场明确列出的签证费和服务费。
4. 保存缴费凭证、申请编号和护照返还凭证。

!!! tip "递签前的经验建议"
    按材料清单顺序整理原件和复印件，另外保存一套完整扫描件。所有法文或英文说明信保持简短，确保日期、金额和申请表相互一致。

## 等待结果与领取护照

递交材料不等于签证获批。处理期间如收到补件或核验通知，应按通知要求和期限回复。查询页面显示“护照可领取”通常只代表审理结束，不代表已经获签；拿到护照后才能确认结果。

收到护照后，立即检查：

- 姓名、护照号码和出生日期是否正确。
- 签证类别及 `ETUDIANT` 等标注是否符合申请目的。
- 签证起止日期和入境次数是否满足行程。
- 签证页是否有明显印刷错误。

发现错误时，应尽快联系受理中心，不要自行修改签证页。

## 如果收到拒签决定

拒签决定通常会说明理由和救济方式。申诉对象、期限和提交方式应以决定书原文为准；不要把其他人的期限直接套用到自己的案件。

你可以先整理：

- 拒签决定书和递签材料副本。
- 能够回应拒签理由的新证据。
- 学校开学日期及是否允许延期入学的书面说明。

如涉及紧迫期限、材料真实性争议或复杂法律问题，建议咨询熟悉法国签证法的专业律师。

抵法后的签证验证、学生居留续签和 ANEF 材料，请继续阅读[法国学生居留办理与续签指南](../after/residence.md)。
