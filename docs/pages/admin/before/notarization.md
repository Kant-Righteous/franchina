# 中国学生赴法常用公证办理指南

本文只介绍由**中国内地公证机构出具的涉外公证书**，范围包括出生、高考成绩单、高中毕业证和大学成绩单公证。

!!! warning "不是所有学生都要办理"
    学校、Campus France 和法国具体用文单位的要求可能不同。先查看你自己的申请清单，再决定办理哪一种公证、使用什么语言；不要因为他人办理过，就默认四类公证都必须准备。

## 先确认是否需要公证

开始办理前，先向要求你提交材料的机构确认：

1. 要的是原件扫描件、公证书、认证报告，还是翻译件？
2. 要公证某个事实，还是公证某份证书、成绩单与原件相符？
3. 接受中文材料，还是要求英文或法文版本？
4. 是否指定文件格式、提交方式或出具时间？

如果要求来自 Campus France，应以你在申请系统中看到的当前材料清单和通知为准；如果要求来自学校或法国行政机构，应保留对方的书面说明，办理时交给公证机构确认。

## 出生公证

### 证明什么

出生公证通常证明申请人的出生日期、出生地点及父母信息等出生事实。

### 一般需要准备的材料

- 申请人的身份证、户口簿等身份证明。
- 出生医学证明、户籍档案或其他能够证明出生事实的材料。
- 公证机构要求时，提供父母身份证明、户口资料或亲属关系辅助材料。
- 公证机构根据个案要求的补充证明。

## 高考成绩单公证

### 证明什么

高考成绩单公证通常证明有关高考成绩证明的真实性，或证明成绩单复印件与原件相符。公证机构需要能够核实成绩材料的来源。

### 一般需要准备的材料

- 申请人的身份证、户口簿等身份证明。
- 省级教育考试机构、招生考试机构、学校或档案保管单位出具的正式成绩证明。
- 原始成绩材料无法直接核实时，公证机构要求的查询结果或补充证明。

## 高中毕业证公证

### 证明什么

高中毕业证公证通常证明毕业证书的真实性，或证明证书复印件与原件相符。它主要针对具体证书，不应自动理解为对全部高中学习经历的证明。

### 一般需要准备的材料

- 申请人的身份证、户口簿等身份证明。
- 高中毕业证书原件。
- 公证机构无法直接核实时，由毕业学校、教育主管部门或档案保管单位出具的证明。
- 姓名发生变化时，能够说明新旧姓名关系的材料。

## 大学成绩单公证

### 证明什么

大学成绩单公证通常证明学校出具的成绩单真实，或证明成绩单复印件与原件相符。公证内容以学校正式出具并能够核实的成绩单为基础。

### 一般需要准备的材料

- 申请人的身份证、户口簿等身份证明。
- 由学校教务部门、档案馆或其他有权部门出具的正式成绩单。
- 在读证明、毕业证或学位证等用于辅助核实身份和学习阶段的材料。
- 公证机构要求时，由学校提供的核实方式或补充证明。

## 一般办理流程

1. **确认要求**：向学校、Campus France 或具体用文单位确认公证事项和语言。
2. **咨询公证机构**：通过[中国法律服务网](https://www.12348.gov.cn/)或当地司法行政机关公布的名录查找正规公证机构，说明文件将在法国使用。
3. **准备材料**：按公证机构针对你的情况给出的清单准备原件和证明材料。
4. **提交申请并配合核实**：公证机构可能向学校、考试机构、医院、派出所或档案单位核实材料。
5. **校对公证书**：重点检查姓名拼写、出生日期、证件号码、学校名称、课程和成绩。
6. **领取并保存**：保存纸质公证书，同时扫描封面、正文、译文和印章页。

!!! note "材料、费用和时间没有全国统一答案"
    不同公证事项、地区和材料核实难度会影响受理要求、费用及办理时间。应以承办公证机构针对本人的正式答复为准，不要把网络经验中的材料数量或办理天数当成统一标准。

## 选择中文、英文还是法文

涉外公证书可以根据办理机构能力和用文单位要求附外文译文。选择语言时：

- 用文单位明确要求法文时，按其要求准备法文版本。
- 用文单位接受英文时，可以询问是否接受附英文译文的公证书。
- 对方没有说明时，先书面询问，不要自行判断英文一定可以替代法文。
- 已有学校英文成绩单，也要确认对方需要“学校英文原件”还是“附英文译文的公证书”。

外文姓名应优先与护照一致。学校名称、专业和课程名称应尽量使用学校官方译法，并在领取时逐项校对。

## 公证、学信网认证和普通翻译的区别

| 文件类型 | 主要作用 | 不能替代什么 |
|---|---|---|
| 公证书 | 由中国内地公证机构依法证明特定事实、证书或文书 | 不能自动替代用文单位指定的认证报告 |
| 学信网认证或验证报告 | 对学信网当前服务范围内的学历、学籍、学位或成绩等信息进行查询、验证或认证 | 不是公证书，也不覆盖所有高中、高考或个人材料 |
| 普通翻译 | 把文件内容转换成另一种语言 | 不证明原件真实，也不等于公证或学信网报告 |

是否需要学信网报告，应查看[学信网](https://www.chsi.com.cn/)当前可申请项目以及学校、Campus France 的具体要求。不要因为已经做了普通翻译，就默认完成了公证；也不要因为已有学信网报告，就默认不再需要公证。
