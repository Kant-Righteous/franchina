# 行李清单建议

赴法国前，行李不宜追求“带得越多越好”，更重要的是把证件、关键材料和抵达初期真正用得上的物品准备齐。很多生活用品到法国后都可以再买，优先考虑重量、体积、航司托运限制和你落地后的前两周需求。

## 证件和文件

- 护照原件
- 法国签证页或有效居留相关材料
- 学校录取通知、注册证明、住宿证明等入学文件
- 国内身份证、户口本关键页复印件
- 证件照

!!! tip "如果可以，把某些文件存成电子版"
    关键文件可以准备少量纸质复印件，其余材料保存清晰扫描件。抵法后可以在学校、图书馆或打印店继续打印。

### 按需准备

以下材料并非每名留学生都要办理，应根据学校、医保、CAF、住宿和个人计划决定：

* 出生证明或出生公证
* 学校要求的其他公证、认证或法语翻译材料（比如毕业证公证、成绩单公证）
* 法语、英语或其他语言成绩证明
* 国内身份证和户口本关键页的复印件或扫描件
* 健康记录、疫苗接种记录或国际保险证明
* 中国驾照和符合要求的法语翻译件，仅限计划在法国驾驶的人

出生证明等民事状态材料可能在办理法国医保、CAF等手续时使用，但具体文件形式、翻译方式和有效期应以办理机构的最新要求为准。

!!! note "不要把关键材料全部放托运行李"
    托运行李延误或丢失时，最麻烦的往往不是衣物，而是证件和入学文件。随身行李里至少保留一套完整的关键材料。

### 随身行李提醒

证件和入学材料尽量集中放在一个随身文件袋中，方便过海关、入学报到和临时核验时快速取用。

## 随身行李

- 手机
- 手机充电器和充电线
- 笔记本电脑（平板电脑）及充电器
- 耳机
- 欧标转换插头随身一个
- 充电宝
- 取卡针
- 纸巾和湿巾
- 口罩若干
- 水杯

## 衣物

### 基础衣物

- 短袖或打底上衣
- 长袖上衣
- 长裤
- 短裤或夏季下装
- 内衣
- 袜子
- 睡衣
- 一件保暖内层
- 一件防风或防雨外套
- 一件适合抵达季节的外套

数量可以参考 7～10 天换洗需求，再根据住宿是否有洗衣机、个人洗衣频率和行李额度调整。

### 鞋类

- 一双适合长距离步行的日常鞋
- 一双备用鞋
- 一双室内拖鞋
- 正装鞋、登山鞋或运动专项鞋，按实际需求携带

### 按需携带

- 一套相对正式的衣服
- 泳衣、泳帽和泳镜
- 运动服
- 保暖帽、围巾和手套

## 供电和电子设备

- 欧标转换插头 3～4 个
- 两块质量可靠的插线板
- 手机和电脑原装或可靠充电器
- 关键设备的备用充电线
- U 盘或移动硬盘，确有文件存储需要时携带
- 鼠标、键盘或数位板等长期使用的学习配件

## 洗漱和个人护理

- 牙具套装
- 毛巾
- 梳子
- 刮胡刀或其他日常护理工具
- 指甲套装
- 个人长期使用的护肤或护理用品
- 隐形眼镜及护理用品，按个人需求

## 厨房用品和食品

- 餐具
- 烧水壶
- 电饭煲
- 空气炸锅
- 中国的特色食品或调料

锅具和厨房电器不仅占用空间，还需要考虑住宿规定、输入电压、功率和实际使用频率。

按需携带，法国基本都能买到（实在不行可以网购），区别是价格可能会贵点。

!!! danger "注意食品入境限制"
    从中国等非欧盟国家进入法国时，肉类、肉制品、牛奶和多数乳制品原则上不能放入个人行李。

## 支付和出行用品

### 银行卡和现金

- VISA或MASTER卡，保证欧洲能用的信用卡（卓隽、长城全币种...）
- 适量欧元现金

!!! warning "大额现金需要申报"
    携带达到或超过 10,000 欧元的现金及部分等价资产跨境时，需要按照法国海关规定申报。

### 日常出行

- 背包
- 斜挎包或贴身包
- 折叠雨伞
- 卡包（很好用）或钱包
- 太阳镜

## 药品和健康用品

- 个人长期服用的药物
- 本人平时确实使用过的退烧或止痛药
- 少量肠胃不适用药
- 少量过敏用药
- 创口贴
- 简单的消毒和外伤处理用品
- 体温计
- 本人确实需要的外用药
- 口罩若干

## 哪些东西不建议带太多

- 厚重但使用频率不高的日用品。
- 体积大、到法国容易买到的锅具、餐具和清洁工具。
- 数量过多的鞋子和衣服。
- 未确认是否符合航空和入境要求的食品、液体和粉末。

## 出发前检查

出发前一晚建议再检查一次：

1. 护照、签证、机票和住宿信息是否都在随身包里。
2. 手机、电脑和充电器是否已经充满电。
3. 重要文件是否已经拍照或扫描备份。
4. 行李标签、姓名拼写和联系方式是否正确。
5. 机场到住处的路线、接机人联系方式和第一晚入住方式是否清楚。

## 一个实用原则

如果一件东西“法国很容易买到、价格差异不大、丢了也不影响入境和报到”，通常就不必从国内辛苦带过去。反过来，证件、资料、药物和到校第一周就要用的东西，应该优先放进随身行李。
