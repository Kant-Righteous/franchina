# 关于我们

欢迎来到 **FranChina** —— 陪伴您走过留法生活的百宝箱！💼✨

## 🌟 我们的初心

每一个选择法兰西的留学生，都曾经历过面对繁琐行政手续时的迷茫与无助。从办理长居、申请 CAF，到激活 Ameli 医保，法国的种种“特色”行政流程常常让人感到头疼。

在这个平台上，我们希望把那些曾经走过的弯路、踩过的坑，转化为一份份清晰、温暖的避坑指南。这里不仅仅是一个冷冰冰的信息库，更是来自学长学姐们的经验传递与互助社区。
