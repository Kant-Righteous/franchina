# 高铁与飞机

## 火车 (SNCF)

法国国家铁路公司 **SNCF** 运营着全国铁路网络，是城际出行最主要的方式。👉 [查看 TGV INOUI 路线地图](https://www.sncf-connect.com/train/horaires/carte-plan-reseau-tgv-inoui) | [SNCF 全国铁路网络地图](https://www.sncf-reseau.com/fr/carte/railway-maps)

### 主要列车类型

| 类型 | 说明 | 特点 |
|---|---|---|
| **TGV INOUI** | 高速列车，连接各大城市 | 速度快（最高 320km/h）、设备好、价格较高 |
| **OUIGO** | 廉价高速列车（SNCF 旗下） | 票价低（最低约 10€ 起），但行李有严格限制，部分站点离市中心较远 |
| **Intercités** | 城际列车 | 连接 TGV 未覆盖的中型城市，速度介于 TGV 和 TER 之间 |
| **TER** | 区域列车 | 深入各城镇，票价相对固定，无固定座位，当日票可乘当天任意班次 |
| **RER** | 区域快铁（巴黎及周边） | 属于巴黎公共交通，可往返凡尔赛宫、迪士尼乐园等 |

此外，SNCF 还运营多条**跨国高速列车**：Eurostar（英国）、Thalys（比利时/荷兰/德国）、TGV Lyria（瑞士）等。

## 飞机

### 欧洲短途：廉价航空

法国境内及欧洲短途旅行，廉价航空常常比火车更便宜（尤其提前购买）。

### 主要廉价航空

| 航空公司 | 说明 | 基地/枢纽 |
|---|---|---|
| **[easyJet](https://www.easyjet.com/)** | 欧洲最大廉航之一 | 巴黎 CDG / 里昂 / 尼斯等 |
| **[Transavia](https://www.transavia.com/)** | 法航旗下廉航 | 巴黎 ORY |
| **[Ryanair](https://www.ryanair.com/)** | 欧洲票价最低廉航 | 巴黎 BVA（博韦，距巴黎约 85km）等 |
| **[Vueling](https://www.vueling.com/)** | 西班牙廉航，飞南欧多 | 巴塞罗那枢纽 |
