# 治安指南

图卢兹整体治安在法国大城市中属于中等水平，市中心、大学周边白天较为安全；但和所有大城市一样，部分街区需要提高警惕。本页整理图卢兹治安分区总览与主要街区的安全情况，供选房和日常出行参考。

!!! note "阅读提示"
    - 总览图中**红色最危险，橙色次之，紫色需提高警惕**，夜间尽量避开。
    - 分区情况整理自本地生活经验与公开资料，最后核验：**2025 年 8 月**。治安状况会随时间变化，请以实际情况为准，仅供参考。
    - 租房签约前，建议对照下文治安分区总览图查看目标住址所在街区。

## 日常安全建议

!!! tip "出行与防范"
    - 深夜尽量结伴出行，避免穿越上述治安较差街区；等车、步行时留意身边环境，不要沉迷手机。
    - 火车站 Gare Matabiau 周边人流复杂，注意随身财物，防范扒手。
    - 遇紧急情况拨打 **17**（警察）或欧盟统一紧急电话 **112**，详见[应急电话](../help/emergency.md)。
    - 更多租房选址注意事项，见[生活圈](life.md)。
