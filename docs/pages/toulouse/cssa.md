# 图卢兹学联
<p style="font-size: 1.1rem; color: var(--md-default-fg-color--light); margin-top: -0.6rem; margin-bottom: 1.5rem;">图卢兹中国学者学生联合会 (UCECF-ST)</p>

图卢兹中国学者学生联合会（简称“图卢兹学联”，UCECF-ST）于 2002 年注册成立，是为留图广大中国留学生、学者服务的合法组织。

“服务学人”作为图卢兹学联的精神，始终贯穿于图卢兹学联所展开的一切活动中。举办多种形式的中法文化交流活动，积极对外弘扬中国文化特色，为推动两国友好关系的向前发展做出积极的贡献；与图卢兹市政职能部门积极合作，并与图卢兹各高校、法中友好人士、华人协会等保持了良好的关系，经过多年的发展与壮大，已发展成在图卢兹华人学生学者中最具影响力、凝聚力的组织之一。

---

## 核心职能与部门架构

学联下设主席团及若干执行部门，各部门分工协作，共同服务本地华人学子社群：

| 部门 | 主要职责 |
|---|---|
| **主席团 (Bureau)** | 统筹学联全局运作、对外事务联络、代表学联对接使领馆与法国高校及政府机构。 |
| **活动部 (Pôle Événementiel)** | 策划并执行开学迎新见面会、中秋国庆晚会、全法春晚分会场、学术沙龙、户外郊游与体育赛事等。 |
| **宣传部 (Pôle Communication)** | 负责微信公众号、小红书等官方新媒体运营，制作活动推文、海报视觉设计、摄影摄像及视频剪辑。 |
| **外联部 (Pôle Partenariat)** | 拓展本地企业与商家赞助合作，争取学生专属折扣，联络各校友会及兄弟学联。 |
| **生活互助部 (Pôle Entraide)** | 负责新生抵法指引、租房与二手信息交流审核、行政手续答疑以及突发困难求助对接。 |

## 历年品牌活动

- **秋季迎新见面会**：为初到图卢兹的学子系统讲解行政手续、租房、交通、学医与安全常识。
- **西南春晚与节日庆典**：汇聚图卢兹各大高校中国学子与国际友人，展现中华传统文化与青年风采。
- **羽毛球与足球友谊赛**：丰富课余文化生活，增进各大实验室与工程师院校学子之间的情谊。
- **职业发展与校友分享会**：邀请在法优秀学长学姐与企业嘉宾分享实习求职与学术科研经验。
