# 🎒 行前准备清单

## ✈️ 重要证件与资料（随身携带）

!!! tip "💡 关键材料，请勿托运！"
    这些是你进入法国、办理学校与生活事务时最关键的材料，**请务必放在随身背包里，绝对不要放入托运行李中**（以防行李延误或丢失导致无法入境或注册）。

- [ ] **护照 + 签证**（确保护照有效期充足）
- [ ] **学校录取通知书 / 注册证明**（海关可能会查）
- [ ] **出生证明及双认证**（办理房补 CAF 的核心材料）
- [ ] **证件照**（1寸 / 2寸各准备若干张，法国照相亭较贵）
- [ ] **驾照及翻译件**（如果有计划在法国开车）
- [ ] **欧元现金**（建议 100–200 € 零钱备用，不要带大额钞票）
- [ ] **国际信用卡 / 银行卡**（Visa 或 Mastercard）【中国银行的很好用】
- [ ] **健康保险 / 旅行保险证明**
- [ ] **电子设备备份**：所有重要文件的复印件 + 电子扫描件（存放在云端/邮箱）

## 👕 衣物与穿搭

!!! info "🌥️ 法国气候提示"
    法国气候多变，尤其是北部（如巴黎）冬天湿冷。建议采用**“洋葱式穿衣法”**（层叠穿搭），方便室内有暖气时穿脱。

### ✅ 基础衣物
1. [ ] 内衣、袜子、睡衣（足够一周换洗）
1. [ ] T恤、衬衫、长袖上衣
1. [ ] 牛仔裤 / 休闲裤 / 裙装
1. [ ] **轻便外套**（春秋用）
1. [ ] **冬季保暖大衣 / 羽绒服**（必带一件）
1. [ ] 雨衣 / 结实的折叠伞（法国雨季常见，且风大）

### 👟 鞋类
1. [ ] **舒适的日常步行鞋**（法国很多石板路，走路很多）
1. [ ] 正式场合鞋（皮鞋/高跟鞋，视需求带一双即可）
1. [ ] 室内拖鞋（法国超市大多是棉拖，塑料凉拖较少见）

## 🔌 电子设备与文具

1. [ ] **手机 + 充电器**
1. [ ] **笔记本电脑 + 充电器**
1. [ ] **国际电源适配器**（转换插头）：法国插座为双圆孔（欧标/德标）
1. [ ] **多孔插线板**（带一个国标插排很实用，解决插头不够用的问题）
1. [ ] 移动电源（Power Bank）
1. [ ] 耳机、U盘 / 移动硬盘
1. [ ] 笔记本、笔（法国文具较贵且书写习惯不同，建议自带少量）
1. [ ] 学术词典 / 电子词典软件

## 🧴 日常生活 & 洗漱用品

!!! question "🤔 需要带很多洗护用品吗？"
    **不需要！** 法国超市（Carrefour, Auchan）和药妆店（Pharmacie）非常发达，价格也很亲民。初期只需携带**旅行装**过渡即可。

1. [ ] 牙刷、牙膏、洗发水、沐浴露（旅行装）
1. [ ] 毛巾（1-2条，刚落地当晚用）
1. [ ] 常用药（**划重点**：感冒药、止痛片、肠胃药、消炎药、过敏药。处方药请带好医生处方翻译件）
1. [ ] 梳子、剃须刀、指甲剪
1. [ ] **眼镜 / 隐形眼镜**（在法国配眼镜很贵且流程长，建议国内多配一副备用）

## 🍳 其他实用小物

这些东西虽然不大，但在留学生活中会派上用场：

1. [ ] **日常背包**（上课/通勤用，防盗性能好一点最佳）
1. [ ] **折叠水壶**（如果你习惯喝热水）
1. [ ] 床上用品（床单/被套：先确认宿舍床尺寸。如果不确定，可带一套旧的或简易的，落地后去 IKEA 更新）
1. [ ] 筷子 / 便携餐具（吃泡面神器）
1. [ ] 小收纳袋 / 压缩袋（打包行李神器）

## 🚫 不建议托带的东西

!!! failure "🙅 没必要占据行李额度"
    以下物品通常**不需要**从国内千里迢迢带过来：

    *   **大量食物/调料**：中超（亚超）在法国大城市遍地都是，老干妈、火锅底料都能买到。
    *   **肉类/生鲜**：**绝对禁止**携带入境，会被海关没收并罚款！
    *   **大型厨房电器**（电饭煲等）：电压虽然兼容，但占地且易坏，法国也能买到或收二手。
    *   **笨重的教科书**：除非教授指定，否则大部分资料都在线或图书馆有。

## 📦 行李打包技巧

> **行李额度**：大多数国际航班允许托运 **2件 × 23kg**，登机箱 **1件**。请务必出发前确认购票信息。

1.  **分装原则**：重物（书、鞋）放下层，衣物卷起来塞缝隙。
2.  **易碎品**：用厚衣物包裹放在中间。
3.  **甚至可以留白**：留一些箱子空间，因为你回国时一定会有更多东西要带回去！
