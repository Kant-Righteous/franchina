# 旁白录音指南

把录好的旁白放在这个文件夹，运行一条命令，字幕、画面节奏和成片会自动按你的录音重新对齐。

## 录音稿

语气像给刚到法国的学弟学妹发一条语音：平静、清楚、带一点温度，不用播音腔，也不用刻意热情。逗号处自然停顿；顿号（、）处稍微停一下，画面里的图标会卡在这些停顿上出现。

| 段落 | 文件名 | 稿子 | 参考时长 | 不超过 |
| --- | --- | --- | --- | --- |
| 1 | `france` | 刚到法国的时候，住哪里、怎么坐车、银行卡怎么开，几乎每件事都要重新找答案。 | 6.8 秒 | 7.6 秒 |
| 2 | `chaos` | 信息其实不少，只是散落在各个网站、群聊和帖子里，翻了很久，也不确定是不是最新的。 | 6.8 秒 | 7.6 秒 |
| 3 | `reveal` | FranChina 把这些整理到了一个地方。出发前的签证、公证，落地后的居留、医保和房补，还有银行、交通和防骗提醒，按你现在的阶段就能找到。 | 11.2 秒 | 12.5 秒 |
| 4 | `toulouse` | 如果你在图卢兹，这里还有更贴近本地的内容：地铁公交和学生票、各个街区的治安、餐厅卫生查询，还有学联的迎新会。 | 8.6 秒 | 9.6 秒 |
| 5 | `rates` | 也有每天更新的实用工具，比如多来源汇率，欧元、美元换人民币，一眼就能对比。 | 6.4 秒 | 7.1 秒 |
| 6 | `outro` | FranChina，陪你走过留法生活的百宝箱。 | 3.1 秒 | 3.6 秒 |

参考时长是当前配音的实际长度。六段加起来不要超过约 48 秒，否则成片会超过 58 秒，脚本会报错提示。单段稍长没关系，画面会自动顺延。

## 录制

- 手机自带录音 App 即可；格式可以是 wav、m4a、mp3、aac、flac。
- 选安静、有窗帘或衣物的房间，减少回声；手机离嘴 20–30 厘米，不要正对着吹气。
- 每段开头和结尾各留 1 秒安静。
- 读错了就把整段重读一遍，不要在中间接着改口，对齐依赖稿子和录音一一对应。
- 「FranChina」怎么读由你决定，全片保持一致即可。
- 录音者需要同意这段声音用于 FranChina 的公开视频。

## 放文件

二选一：

- **分段录**（推荐）：六个文件，按上表命名，例如 `france.m4a`、`chaos.m4a` … `outro.m4a`。
- **一次录完**：一个文件 `full.m4a`，六段之间停顿 1 秒以上。

## 生成

在 `video/` 目录运行：

```bash
python scripts/generate_voiceover.py --source recording
```

脚本会统一各段的音色和响度（需要 `pip install numpy scipy`）、裁掉首尾空白、把字幕和画面重点词对齐到你的停顿，写出 `public/audio/`、`src/data/timeline.json` 和 `captions.srt`，并在本文件夹生成 `alignment.json` 供核对每句的起止时间。之后渲染：

```bash
npx remotion render FranChinaPromo out/franchina-promo.mp4 --codec=h264 --crf=18
```

想回到合成配音，运行 `python scripts/generate_voiceover.py` 即可。
